## 1. SDK 与评估目的

“**SDK**”指随附发布清单所载的 Realtek Connect+ Cloud SDK 评估版本，包含 Native C/C++、Android Kotlin、JavaScript/TypeScript、iOS Swift 与 FreeRTOS/Pro2 套件，以及瑞昱提供的源代码、目标文件、软件库、头文件、示例、文件、清单和更新。

SDK 是尚未正式发布的评估软件，仅供评估者在内部测试、开发、展示及概念验证时，评估其与 Realtek Connect+ 服务的互通性（以下称“**评估目的**”）。SDK 尚未获准用于正式部署、转售或商业运营。
