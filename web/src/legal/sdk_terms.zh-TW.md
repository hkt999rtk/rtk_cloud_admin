## 1. SDK 與評估目的

「**SDK**」指隨附發布清單所載的 Realtek Connect+ Cloud SDK 評估版本，包含 Native C/C++、Android Kotlin、JavaScript/TypeScript、iOS Swift 與 FreeRTOS/Pro2 套件，以及瑞昱提供的原始碼、目的碼、程式庫、標頭檔、範例、文件、清單和更新。

SDK 是尚未正式發布的評估軟體，僅供評估者在內部測試、開發、展示及概念驗證時，評估其與 Realtek Connect+ 服務的互通性（以下稱「**評估目的**」）。SDK 尚未獲准用於正式部署、轉售或商業營運。
